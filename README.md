# my-artifects-

Interactive web experiments (single-file HTML, no build step). Open any file in a browser.

- the-seed.html: scroll-driven 3D sunflower life cycle
- periodic-table.html: 3D periodic table (table / sphere / helix / grid)
- galaxy.html: WebGL spiral galaxy
- day-night-toggle.html: day/night switch scene
- spider-cursor.html: spider that follows the cursor
- scorpion-cursor.html: IK skeleton creature
- black-hole.html: ray-marched black hole
- neural-synapse.html: neuron firing with bloom
